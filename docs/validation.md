специально проверяют механику Reviewer-патча и запроса Architect.

## Реальный контур 1028279 — 5 ноября

Пилот использует контур из
`experiments/workspace/parametrization/zero_shot/validation/initial_samples/1028279.json`
checkout Маслова. Эталонное `building` исключено из входа модели.
Два этажа, высота этажа 3 м и размещение внутри участка — явно заданные
диагностические цели, не ответ или требования исходного benchmark-датасета.

Исходные метрики: `BuildingFloorCount` и `SiteMatch`, без общего score.
Runtime установлен из закреплённого Git commit; VCS provenance сохранён
в `experiment_provenance.json`. Модель — `gpt-6.1-sol`.

| Попытка | Результат | LLM / оценки | Время | Input / output токены |
| --- | --- | --- | --- | --- |
| `…-01` | `failed`, кандидата нет: Enhancer не передал контур; Programmer выполнил только `read_scene()`. | 2 / 0 | 119.38 с | 31 042 / 658 |
| `…-02` | `completed`, выбран оценённый `c0001`: `floor_count=2`, `site_match=1`. | 3 / 1 | 88.86 с | 50 698 / 2 159 |

После первой попытки конфиг уточнён: ответ Enhancer должен содержать полный
контур и единицы. Передача исходного context напрямую Programmer не добавлялась;
порядок ролей Text2BIM сохранён. Пустая сцена не была принята за результат.

До LLM была также отклонена установка без VCS provenance: pip сохранил уже
установленную версию `0.1.0`. Повтор с `--force-reinstall --no-deps` установил
нужный commit; проверка pin не ослаблялась.

Успешный цикл: Enhancer → Programmer → Reviewer, одна попытка кода.
Получен footprint 20×28 м, два слоя 0–3 и 3–6 м. Исходный конвертер подтвердил
полное покрытие footprint контуром участка. Дополнительная проверка на macOS
исходным mesh-компилятором дала 560 м², 3360 м³, `is_watertight=true`,
`is_volume=true`. Отчёт — `geometry_validation.json` успешного запуска.

Артефакты обеих попыток:
`runs/maslov-linux-site-1028279-20261105-01/` и
`runs/maslov-linux-site-1028279-20261105-02/`.

## Воспроизводимость и сохранность результатов

В `runs/` сохранены реальные запросы/ответы, конфиги, промпты, код, snapshots,
отчёты, usage и статусы. Эти каталоги игнорируются Git и не входят в clone;
таблицы выше — версионируемая сводка фактически выполненных запусков.

Linux использовал read-only mounts исходного checkout, CLI и auth.json;
авторизация не включалась в образ или результаты. Codex API-ключи не
передавались. Git safe.directory задавался окружением контейнера.

Проверен официальный Linux arm64 CLI 0.164.0 из
[release Codex](https://github.com/openai/codex/releases/tag/rust-v0.164.0),
`codex-aarch64-unknown-linux-musl.tar.gz`, SHA-256:
`29a507a2a3fd8f6cd94b96b762d281d299d15d7902dee6132d314b78cf9108eb`.

Usage CLI включает служебный контекст Codex и может содержать cached input;
он не равен длине промптов Text2BIM. Денежная стоимость для подписки не
вычислялась. На другой машине время и результаты LLM могут отличаться.

## Что эти проверки не подтверждают

Общий benchmark, серия реальных участков, многозданные задачи, все девять
общих метрик и физические оценщики не проверены этим пилотом. Нет результата
сравнения с методом Маслова или воспроизведения качества исходной статьи.
Живые вызовы OpenAI API отдельно не выполнялись; тестируется его SDK transport.

Для следующего эксперимента нужны реальные requirements, подключённый
dataset/split, проверенные общие метрики, закреплённые условия и отчёт обо
всех задачах. Конкретные критерии завершения — в
[плане](../Text2BIM-Massing-implementation-plan.md).
