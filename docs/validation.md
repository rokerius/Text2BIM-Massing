## Что эти проверки не подтверждают

Общий benchmark, серия реальных участков, многозданные задачи, все девять
общих метрик и физические оценщики не проверены этим пилотом. Нет результата
сравнения с методом Маслова или воспроизведения качества исходной статьи.
Живые вызовы OpenAI API отдельно не выполнялись; тестируется его SDK transport.

Для следующего эксперимента нужны реальные requirements, подключённый
dataset/split, проверенные общие метрики, закреплённые условия и отчёт обо
всех задачах. Конкретные критерии завершения — в
[плане](../Text2BIM-Massing-implementation-plan.md).

## Checkpoints после исследовательского ревью

В версии до исправления оба восстановленных контрпримера падали: replay
исходного source строил 6 м вместо snapshot/report 3 м; отдельный патч
получал InterpretorError из-за values_after_commit, определённого в успешном
скрипте после commit. Сам counterexamples.json автора не был предоставлен;
примеры реконструированы по описанию и сохранены в test_checkpoints.py.

После фикса прошли 123 теста на macOS и в Linux с точным checkout Маслова.
В Linux новый wheel установлен в site-packages; worker запускается с -I,
поэтому проверялся именно исправленный установленный runtime. Ruff,
pip check, wheel/sdist и исходные hashes проходят.

Семь новых регрессий проверяют код выбранного snapshot, поздние variables,
commit внутри цикла, восстановление ранней ветки и следующий патч, ошибку
после оценки, pure-variable update без новой оценки, мутабельные аргументы,
сохранение IDs/math aliases, native Python replay и отказ повреждённого журнала.
Каждый сохранённый checkpoint сравнивается со snapshot/state своего кандидата.
Replay не выполняет LLM/evaluator, а прежние report/геометрия не заменяются.
Метрики и их численные допуски не правились.

Артефакты нового формата описаны в checkpoints.md. Старые результаты сохраняют
свою версию и исходные значения; они не объявляются недействительными по одному
лишь несовпадению source с геометрией. Живая проверка нового feedback-примера
фиксируется отдельно после выполнения.


Живая Linux-проверка исправленного runtime `62162651ce3bdd2d7ed0a9373ef6a392c4642a36`:
`examples/checkpoint_feedback_task.json`, gpt-6.1-sol, reasoning low,
Codex CLI 0.164.0 через подписку, исходный BuildingFloorCount (3 м на этаж).
Первый скрипт построил 3 м, commit/evaluate/select, затем определил

Результат completed, выбран оценённый c0002, floor_count=2. Путь ролей
Enhancer → Programmer → Reviewer → Programmer → Reviewer. Расход —
5 LLM-вызовов, 2 оценки, 2 попытки кода, 68.30 с;

После запуска оба code.py и selected_code.py исполнены обычным Python:

Проверено по AST, что variables первого скрипта определены после commit,
а следующий патч их читает. Replay не добавил LLM/оценок. Report c0001

Локальные артефакты: `runs/checkpoint-linux-feedback-20261105-01/`, включая
