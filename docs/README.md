отдельно от исторического журнала, чтобы прошлые ограничения не воспринимались
как актуальный статус.

`text2bim-diff.md` и `adaptation-lock.json` генерируются из кода и ручного
`adaptation-spec.json`. Их не следует править вручную; порядок обновления —
в CONTRIBUTING. Оригиналы из `upstream/` не являются рабочим backend.

Сырые результаты проверок хранятся локально в `runs/`, не включаются в Git
и не появляются при клонировании репозитория. Их сводка находится в validation.
